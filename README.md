# 📊 Project Management Dashboard (Power BI)

## 📌 Overview
This project focuses on analyzing project performance using an interactive Power BI dashboard. It helps track key metrics such as project cost, benefits, completion percentage, and overall status.

---

## 🎯 Objective
- Monitor project progress and performance  
- Analyze cost vs benefit of projects  
- Identify delays and inefficiencies  
- Support data-driven decision-making  

---

## 🛠️ Tools & Technologies
- Power BI  
- DAX  
- Excel  

---

## 📊 Dashboard Features
- KPI cards showing total cost, benefits, and completion %  
- Project status tracking (Completed / In Progress / Delayed)  
- Phase-wise project analysis  
- Interactive filters for better insights  
- Visual charts for easy understanding  

---

## 📈 Key Insights
- Identified projects with lower completion rates  
- Highlighted cost-heavy projects affecting performance  
- Improved visibility into project progress and efficiency
